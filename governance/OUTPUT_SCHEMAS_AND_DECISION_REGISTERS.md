## Formal Decision Record (v1.2)

Decision: PURSUE / CONDITIONALLY PURSUE / HOLD / DECLINE / PURSUE AS LEARNING OPTION

| Field | Purpose |
|---|---|
| Why | Concise decision logic |
| Strongest evidence | The evidence carrying most weight |
| Principal uncertainty | The unknown most capable of changing the verdict |
| Conditions | Requirements for continued pursuit |
| Circuit breakers | Explicit pre-committed exit conditions |
| First proof point | The earliest governed test of real value |
| Reconsideration trigger | Evidence that would reverse or materially alter the decision |
| Confidence | High / Medium / Low |
| Evidence assurance | Declared or Enforced, and the basis |
| Authority assurance | Declared or Enforced, and the basis |
| Permitted next action | The only next actions this decision authorises |
| Human Captain | Final authority remains exclusive |

Absence of a permitted external Action means none is authorised. This snapshot is Declared, not Enforced.

## Quality gate

The output fails if it could be reused unchanged for another organisation, repeats the website, hides uncertainty, invents candidate evidence, confuses output with impact, proposes AI without workflow and governance analysis, or treats a recommendation as an authorised external Action.
