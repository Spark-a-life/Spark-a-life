# ADR-000: Public hub is not an estate heap

- Status: Proposed
- Date: 2026-11-14
- Decider: Human Captain (pending)

## Context

Draft branches attempted to place a seven-package monorepo and an AIOS governance tree at the root of the GitHub profile repository. November positioning work produced portable teaching and decision-spine artefacts that do not require those trees to be useful.

## Decision

`Spark-a-life/Spark-a-life` remains a thin public hub: profile README, architecture docs, and checksummed portable packs. AIOS and publishable modules live as siblings. Private estate systems stay private. Teaching fixtures never become authoritative witness stores.

## Consequences

- Merging AIOS or the monorepo onto `main` is out of policy.
- New capability arrives as a pack or a sibling repo, not a new top-level platform folder.
- Release claims require pack manifests and Continue / Revise / Stop criteria.
- Founder curation load must be measured before scaling Captain networks.
