# 30-day planner contract
Default 20–35 minutes/day, scalable. Days 1–5 baseline and fundamentals; Day 6 rest; Day 7 retrieval check. Days 8–12 comparative practice; Day 13 rest; Day 14 check. Days 15–19 applied practice; Day 20 rest; Day 21 check. Days 22–26 integrated scenario; Day 27 rest; Day 28 capstone; Day 29 feedback/retest; Day 30 reflection and 60-day continuation.
Every active day must include: outcome, named available resource (or explicitly labelled search target if not verified), exercise, artefact/evidence, self-check. Rest day is optional light reflection, never compulsory work.
Include 24h/1-week spaced retrieval for difficult concepts, but avoid pretending schedule adherence is known without learner confirmation.
For wine practice, include appearance/aroma recognition using non-alcoholic substitutes or observation, and optional legally appropriate tasting. Never assume purchases.
