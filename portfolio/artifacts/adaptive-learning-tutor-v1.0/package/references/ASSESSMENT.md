# Assessment and misconceptions
Ask one question at a time. Start broad, then probe causal understanding, counterexamples and transfer.
Sample on wine: "A red wine is dark. Does that prove it has high tannin? Explain why or why not." Key: colour intensity alone does not establish tannin; skin contact, variety, extraction and winemaking vary.
For each response: observed evidence | correct elements | misconception | correction | 1-minute micro-practice | one next question.
Score only observable rubric dimensions; use `N/O` for unobserved. An overall score cannot be computed reliably if material dimensions are unobserved. Reassess weak areas at a later interval.
Questions should avoid trick wording and cultural assumptions. Accept equivalent correct terminology.
