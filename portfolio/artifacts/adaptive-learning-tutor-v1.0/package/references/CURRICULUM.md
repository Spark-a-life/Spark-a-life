# Curriculum design contract
- Define target competency as an observable action (e.g., compare two styles with justified sensory evidence), not "know wine".
- Progress through concepts → guided comparison → unsupervised application → critical evaluation → transfer.
- For a 15-chapter request: 3 sections of five chapters, exactly five topics per chapter, plus optional outcome and suggested practice; do not confuse this with a publisher's table of contents.
- Map each chapter to prerequisites, assessment, one common misconception, and low-cost alternative exercise.
- If a specific book is named, distinguish an edition-verified original contents list from an original pedagogical reorganisation.
- Facilitate active retrieval and short concept comparisons instead of passive reading only.
