# System Definition

WiseGen APE Intelligence OS is the canonical governance and intelligence operating architecture for Spark-a-life.

## Architectural invariant

One OS, multiple estates, many runtimes, replaceable models, governed capabilities and one accountable evidence chain.

## Seven operating planes

1. Purpose and Constitutional Plane
2. Governance and Authority Plane
3. Intelligence Estate Plane
4. Orchestration and State Plane
5. Capability Plane
6. Knowledge and Memory Plane
7. Evidence, Assurance and Learning Plane

No runtime may bypass these planes or recreate them as an independent authority system.
