# Safeguard Model

The safeguard model is built around fail-closed behaviour. The system blocks or pauses whenever it cannot establish schema validity, evidence mapping, approved adapter status or human approval for external egress.

## Controls

- Contract validation before execution
- Mission admission before workflow generation
- Runtime budget and circuit breaker
- Loop detector for repeated action signatures
- Scoped capability tokens
- Claim-to-evidence checking
- Privacy source review
- Captain Gate before external action
- Witness Chain audit for material events

## External egress rule

No email, LinkedIn message, CRM write, data-room release or publication is executed by this local reference implementation. It produces governed drafts and review artefacts only.
