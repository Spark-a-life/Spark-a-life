# Fundraising Mission Team Playbook

## Mission sequence

```text
Mission Brief
  -> Captain strategy
  -> Prospect sourcing
  -> Enrichment and scoring
  -> Funder memo
  -> Outreach draft
  -> Compliance review
  -> Creative pack
  -> Data-room checklist
  -> Tracker update
  -> Captain Gate
```

## Roles

The fundraising suite uses fourteen roles. The first ten cover the fundraising workflow. The final four harden the system: Creative Director, Safeguard Governor, Evidence Librarian and QA Evaluator.

## Stage discipline

A prospect may move forward only when the reason for movement is explicit. The tracker records stage, fit score, estimated amount, source, next action, owner and approval status. External outreach remains draft-only until Captain Gate approval.
