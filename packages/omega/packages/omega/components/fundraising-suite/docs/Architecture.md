# Architecture

## Converged architecture

The suite converges creative engineering, MAMT safety and fundraising operations into one governed mission-team architecture.

```text
Human Operator
  -> Cockpit Layer
    -> Captain Gate
      -> Mission Layer
        -> Fundraising Mission Team
          -> Fundraising Agents
          -> Creative Agents
          -> Safeguard Agents
          -> Evidence Agents
          -> Operations Agents
            -> Task Contracts
              -> Tool Policies
                -> Runtime Governor
                  -> Model Router
                    -> Adapter
                      -> Evaluation
                        -> Witness Chain
```

## Why v1.1 is the base

v1.0 supplied the creative engineering canon, adapter posture, rubrics and witness-chain foundation. v1.1 added the correct MAMT and safety direction: runtime governor, credential broker, mission admission, role compilation and operational safety tests. The v1.2 fundraising suite extends v1.1 because its safety architecture is already executable.

## New convergence in v1.2

- Fundraising becomes the mission-specific workflow.
- Creative engineering becomes a bounded pack for campaign narrative, outreach, LinkedIn and visual prompt generation.
- Safeguards become mandatory admission, claim review, privacy review, runtime budget and Captain Gate controls.
- Evidence becomes the shared substrate for memos, outreach, creative and compliance.
- Model routing remains abstract and replaceable.
