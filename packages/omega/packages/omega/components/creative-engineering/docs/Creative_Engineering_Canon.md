# Creative Engineering Canon

Creative Engineering is the systematic design, orchestration, governance, evaluation and continuous improvement of AI-assisted creative workflows to produce reliable, reproducible, auditable and deployable creative outcomes across models and modalities.

## Lifecycle

Discover -> Frame -> Design -> Reference -> Compose -> Generate -> Evaluate -> Govern -> Refine -> Approve -> Deploy -> Observe -> Learn -> Improve.

## Non-negotiables

- Creativity must be connected to mission intent.
- Outputs must be evaluated against explicit criteria.
- Reference assets must have provenance.
- Model-specific prompts must be generated from stable contracts.
- Human accountability remains part of the system.
