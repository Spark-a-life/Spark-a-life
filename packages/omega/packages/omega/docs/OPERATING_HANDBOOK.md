# Operating Handbook

## Standard procedure

1. Write a mission contract with measurable success criteria.
2. Validate it using `wisegen-omega validate`.
3. Resolve P0 clarifications or explicitly authorise a declared-assumption path.
4. Supply evidence and classify claims.
5. Run independent advisory review before exposing peer outputs.
6. Preserve dissent during synthesis.
7. Record Captain approval before execution.
8. Execute only bounded, reversible local work in the reference runtime.
9. Verify outputs and the Witness Chain.
10. Complete a retrospective before closing the mission.

## Escalation

Stop immediately when evidence integrity fails, an authority boundary is crossed, a critical assumption is falsified, or execution exceeds its risk budget.
