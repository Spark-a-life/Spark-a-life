# Migration from source repositories

- `creative-engineering` becomes the creative domain plugin.
- `fundraising-suite` becomes the fundraising domain plugin.
- `presentation-intelligence` becomes the presentation domain plugin.
- `workspace-in-the-loop` informs the shared workspace, ranking and Witness Chain doctrine.
- SDIA becomes the mandatory pre-execution control for medium and high-impact missions.

Original repositories remain under `components/`. Teams may migrate incrementally by wrapping their existing CLI or engine behind a versioned plugin contract.
