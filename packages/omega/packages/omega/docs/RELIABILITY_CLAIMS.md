# Reliability Claims and Non-Claims

## Demonstrated

- Schema validation
- Explicit state transitions
- Fail-closed transition enforcement
- Deterministic intent and advisory workflow
- Captain authorisation gate
- Append-only SHA-256 Witness Chain
- Local reference execution without provider credentials
- Automated tests for critical control paths

## Not claimed

- Perfect factual accuracy
- Universal safety
- Production-grade high availability
- Legal or regulatory compliance without jurisdiction-specific review
- Independence merely because multiple roles are produced by one model
- Automatic execution on external systems

Production adoption requires threat modelling, provider-specific adapters, secrets management, observability, load testing, red-team testing and accountable human ownership.
