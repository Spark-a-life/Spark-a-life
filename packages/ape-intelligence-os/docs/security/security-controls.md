# Security Controls

- Default deny for unknown runtimes, capabilities, estates and risk tiers
- Disabled external runtimes until separately assured
- Minimum necessary data classification per capability
- Human approval at medium and high risk
- Critical risk denied in this baseline
- External side effects disabled
- Runtime adapters cannot edit policy through the execution interface
- Witness records include gate, start, completion and failure events
- Configuration verification checks references across estates, capabilities and runtimes
