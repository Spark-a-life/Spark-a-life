# Templates

Reusable starting points promoted from completed runs by the Commons Librarian. A template is promoted only after a run using its pattern has passed the full gate set, which is why this directory grows slowly and on purpose.

| Template | Promoted from | Shape |
|---|---|---|
| `internal-tool` | employee onboarding demonstrator | Role-based records, transitions, approvals, audit, export |
| `hr-system` | employee onboarding demonstrator | Internal tool plus personal-data masking and retention defaults |
| `decision-cockpit` | not yet promoted | Read-mostly view over records with a decision log |

Promotion is governed. See `docs/ROLES.md` on the Commons Librarian: turning one-off outputs into reusable patterns must not let production behaviour change itself.
