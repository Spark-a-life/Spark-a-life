# Changelog

All notable changes to WiseGen Forge. Format follows Keep a Changelog; versioning follows Semantic Versioning.

## [1.0.0] - 2026-07-25

### Added
- First production-grade vertical slice: the twelve-service spine (intent compiler, project service, orchestration engine, agent runtime, model router, tool gateway, policy engine, evaluation engine, witness service, approval service, deployment service, cost governor).
- Nine-stage governed runtime: intake, intent compilation, architecture and risk, mission planning, branchable execution, continuous verification, Captain's Gate, deployment, operational learning.
- Twenty-role registry across Council, Forge, Command, Commons and Market layers, each a versioned authority contract.
- Branchable execution with conservative and performance candidates, separately costed, tested and witnessed.
- Reference demonstrator: Governed Spreadsheet-to-Application Factory over employee onboarding data.
- Tamper-evident witness chain with CLI verification.
- Portable ownership bundle export, with an acceptance test proving the bundle operates without WiseGen Forge.
- Policy-as-code across constitutional, organisational, project, data, security, deployment, model-routing, cost and retention scopes.
- Provider-neutral model adapters: deterministic offline default, plus Anthropic and Ollama adapters behind the same interface.
- Five deployment estates and a network-denied-by-default execution posture.

### Governance
- Captain Rule enforced in code at two hard gates: specification approval before generation, and release approval before deployment.
- Separation of duties proven by adversarial tests: generation cannot approve, approval cannot generate, metering cannot spend, audit cannot deploy.
