## Interpretation notes

- NIST AI RMF is voluntary and risk-based. It is not a certification scheme.
- OWASP cheat sheets provide security guidance, not a complete control framework.
- The Chrome DevTools Protocol tip-of-tree version can change without backwards compatibility guarantees.
- Browser authentication state can contain cookies and headers capable of impersonating an account. This repository therefore avoids persisted personal browser profiles.
